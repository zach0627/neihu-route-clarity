# 方向範圍說明：哪些路段算「往內湖科技園區」

本專案只排名「入園路段」與「園區內路段」。判定完全依官方資料：園區範圍採臺北市商業處公布的門牌範圍，道路位置採 TDX 官方路段編碼（LinkID）的起點、終點與線形，與車流量高低無關。本文件由 2026-10-23 的資料快照產生；重新執行 `npm run data:reference`、`npm run data:aggregate` 後數字可能改變，以「資料來源與計算」頁為準。

v1（2026-10-22）是依道路連接關係人工初選，各筆理由仍保留在 `config/directions.json` 供對照，但不再決定排名範圍。

   機器可讀版本在 `config/park-boundary.json`。這是門牌地址範圍，不是邊界線。

3. TDX 路段編碼：`basic/v2/Road/Link/LinkID`（偵測器所在路段的起點、終點、道路分類）、`basic/v2/Road/Link/CityRoad/Taipei/{路名}` 與 `Road/Link/Shape/Geometry/GeoJson`（列名道路整條的路段與線形）。

## 判定步驟

1. **園區內道路區段。** 把採用的門牌投影到該路的官方線形上。官方範圍為「全部」的道路（基湖路、瑞湖街、洲子街）整條計入；有單雙號之分的道路，取單號側與雙號側範圍重疊的區段（例如港墘路單號 183 號以後與雙號 200 號以後的重疊段）。「以後」的範圍延伸到門牌號碼增加方向的道路端點。本次共 9.98 公里（雙向分計）。
2. **邊界道路。** 官方範圍只有單側門牌的道路，另一側不屬園區，本身不算園區內道路：內湖路一段（雙號 2–520 號）、堤頂大道二段（單號全部）、舊宗路二段（單號全部）、行忠路（單號全部）。
3. **路段位置。** 偵測器所在官方路段的起點或終點，若在園區內道路區段 60 公尺內，即視為位於園區。終點在、起點不在為「入園」；都在為「園區內」；起點在、終點不在為「出園」；都不在為「園區外／邊界」。官方道路分類 2（市區快速道路：堤頂大道、環東大道）與 7（匝道）另列為「市區快速道路」，不列入。
4. **列入排名。** 只排名入園與園區內路段；同一 LinkID 有多支偵測器時只取一支代表（優先序設定於 `config/directions.json`，與車流量無關）。

**60 公尺的依據：** 本次官方路段端點到園區內道路區段的距離，50 公尺以內者都是與園區道路交會的同一路口；其次是 95 公尺的舊宗路二段北端（VRPSV70），經官方路段確認它的終點與港墘路園區段的起點是相距 96 公尺的不同路口，附近也沒有其他園區道路路段開始。因此取 60 公尺。

## 限制

- 這是道路幾何判定，不是車輛目的地調查。入園路段的車在路口也可能直行離開，園區內路段也有穿越車流；偵測器無法追蹤個別車輛。
- 沿邊界道路行駛的車（例如內湖路一段、舊宗路二段）有一部分是要進園區的，但資料無法分辨，因此這些路段只有在終點接上園區內道路時才算入園。
- 門牌範圍以 2026-10-23 查閱的商業處網頁為準；門牌定位與路段編碼版本以 `data/reference.json` 記錄的取得時間與 SHA-256 為準。
- 國道（高速公路局）偵測器已評估：內湖附近 44 支、其中 16 支匝道，但匝道偵測器的 LinkID 指向主線路段，官方幾何無法證明匝道通往園區；本版不列入。
